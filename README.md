# RyuLink MTP

**龙联 MTP（RyuLink MTP）** 是一款面向 **Windows** 的 Nintendo Switch 桌面管理工具，主要用于通过 **DBI MTP** 管理本地游戏资源、查看 Switch 存储信息，并完成安装队列与 NSP/XCI 整合处理。

> 当前仅支持 Windows。项目仍在持续开发中，部分功能尚未开放或仍需进一步稳定。

## 主要功能

### 游戏资源库

- 选择并扫描本地资源目录。
- 识别 `.nsp`、`.nsz`、`.xci`、`.xcz` 文件。
- 支持重新扫描、取消扫描。
- 显示扫描进度、错误与警告信息。

### 游戏合集

- 内置“全部”合集。
- 支持新建、编辑和删除自定义合集。
- 同一个游戏可以加入多个合集。
- 支持为游戏添加和编辑备注。

### MTP 安装

- 检测已连接并运行 **DBI MTP** 的 Nintendo Switch。
- 读取 Switch 的 SD 卡和 NAND 可用空间。
- 支持单个游戏或整套合集加入安装队列。
- 显示安装进度与任务状态。
- 支持失败任务重试和移除。
- 安装前会检查设备连接、存储空间、源文件及安装结果。
- 安装期间锁定其他 MTP 操作，避免多个任务并发访问设备。

### 安装队列

- 安装任务支持持久化保存。
- 应用重启后可恢复未完成的任务状态。
- 统一管理等待中、安装中、失败和已完成任务。

### NSP / XCI 整合

- 选择包含本体、更新补丁和 DLC 的文件夹。
- 自动收集可处理的游戏包文件。
- 支持整合输出为 **NSP** 或 **XCI**。
- 显示处理进度与运行日志。

### Switch 概览

连接设备后可查看：

- Switch 型号 / 序列号
- 系统固件版本
- SD 卡容量与使用情况
- NAND 容量与使用情况
- DBI MTP 连接状态

### 设置与关于

- 查看当前应用版本。
- 更多设置功能仍在开发中。

## 当前状态与限制

- **仅支持 Windows。** 真正的 Windows MTP / DBI 设备访问实现只在 Windows 平台启用。
- “已安装游戏列表与卸载”相关代码已经存在，但由于 Windows MTP 的 COM / RCW 稳定性问题，目前界面暂时隐藏，暂不可用。
- 游戏文件解析和 NSP/XCI 整合依赖内置的 Python `game-core` worker；Python 环境未正确配置时，程序会提示安装或配置。
- 项目仍处于持续开发阶段，功能和界面可能发生变化。

## 使用说明

1. 在 Nintendo Switch 上启动支持 MTP 的 DBI。
2. 使用 USB 将 Switch 连接到 Windows 电脑。
3. 启动 RyuLink MTP，等待程序识别设备。
4. 添加本地游戏资源目录并完成扫描。
5. 选择需要安装的游戏或合集加入安装队列。
6. 确认 Switch 存储空间后开始安装。

## 项目定位

RyuLink MTP 主要解决 Windows 与 Nintendo Switch 之间的本地资源管理和 DBI MTP 操作问题，希望把资源扫描、合集管理、安装队列、设备信息和 NSP/XCI 处理集中到一个桌面应用中。
